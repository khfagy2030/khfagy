Built for teams.

Commit one file. Every developer gets the same rules, and nobody can switch them off.

  • Team policy enforced on every machine
  • Audit log of every action and block, exported to CSV for your auditors
  • Instant alerts on Slack, Teams, Discord or Telegram
  • Freeze a project read-only during a release
  • Runs on your machines: nothing is sent anywhere but your alerts
// khfagy.policy.json
{
  "name": "Acme Security Policy",
  "enforce": {
    "guardSecrets": true,
    "guardCommands": true,
    "guardProjectFence": true,
    "timeMachine": true
  },
  "blockedCommands": ["terraform destroy"],
  "dailyTokenBudget": 2000000,
  "audit": { "dir": ".khfagy/audit" },
  "alerts": { "webhook": "env" }
}
